# GearGo Business Analysis & Requirements

##  Problem Statement
Current Problem:** GearGo currently relies on manual tracking methods, causing frequent equipment double-bookings and operational delays.
Affected Users:** Customers, counter staff, and rental managers.
Business Impact:** Inaccurate availability information causes customer frustration and direct revenue losses.
Proposed Solution Boundary:** A centralized web platform utilizing ASP.NET Core MVC to expose a live catalog, process digital requests, and manage items.

## User Roles
1. Customer: Browses inventory and requests rental time slots.
2. Staff: Processes requests and monitors item turnaround conditions.
3. Manager: Administers catalog data entries and tracks system metrics.

## Use Cases per Role
### Customer
Browse Equipment Catalogue
Filter/Search Inventory by Category
Submit Rental Request

### Staff
Review Pending Rental Requests
Update Equipment Availability Status
View Customer Rental History

## Manager
Add New Equipment to Catalogue
Edit/Update Catalogue Items
Manage System User Accounts
